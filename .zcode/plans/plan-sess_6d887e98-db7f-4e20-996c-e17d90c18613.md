# Vortex 本地网关 HTTPS 支持

## 目标
为本地网关（10168 端口）增加 HTTPS 访问能力：自动生成本地自签证书（mkcert 式体验），可选自动安装 CA 到系统信任，第三方工具即可用 `https://localhost:10168` 访问。

## 方案要点（按推荐默认）
- **证书**：默认首次启用时自动生成本地 CA + `localhost/127.0.0.1/::1` 服务器证书（`rcgen` 生成，持久化到 `<data_dir>/tls/`，密钥 0600）；支持 `VORTEX_TLS_CERT`/`VORTEX_TLS_KEY` 指定外部证书覆盖
- **端口**：同一端口切换协议——`VORTEX_TLS=true` 时 10168 直接变为 HTTPS
- **CA 信任**：macOS 上 best-effort 自动执行 `security add-trusted-cert`（装到用户登录钥匙串，无需 sudo），失败则日志提示手动导入

## 实施步骤

### 1. 后端：TLS 模块与配置（Rust）
- **`crates/vortex-gateway/Cargo.toml`**：新增 `rcgen`、`rustls-pemfile`；`actix-web` 启用 `rustls` feature（走 actix-tls 3.6 + rustls 0.20，与 awc 现有依赖树一致，无版本冲突）
- **`crates/vortex-store/src/config.rs`**：`AppConfig` 新增 3 个字段（读环境变量）：
  - `tls_enabled` ← `VORTEX_TLS`（默认 false）
  - `tls_cert` / `tls_key` ← `VORTEX_TLS_CERT` / `VORTEX_TLS_KEY`（可选外部证书）
- **新建 `crates/vortex-gateway/src/tls.rs`**：
  - `ensure_tls(config)`：外部证书优先；否则检查 `data_dir/tls/` 下 `ca.pem/ca.key/server.pem/server.key`，缺失则用 rcgen 生成 CA（10 年）+ 服务器证书（SAN: localhost、127.0.0.1、::1、本机 hostname），按 `.encryption_key` 的持久化模式落盘
  - `build_server_config()`：组装 rustls 0.20 `ServerConfig`
  - `try_install_ca_trust()`：macOS 执行 `security add-trusted-cert -r trustRoot -k <login.keychain-db> ca.pem`（best-effort，结果写日志）
- **`crates/vortex-gateway/src/lib.rs`（约 :229 bind 处）**：按 `tls_enabled` 分支 `bind_rustls(...)` / `bind(...)`，启动日志带协议 scheme；`ServerHandle`/启停链路（托盘、proxy_service、信号处理）不动

### 2. 前端：网关地址收敛为单点配置
当前 7 处硬编码 `http://localhost:10168`，收敛为 `src/lib/gateway.ts` 的 `gatewayBase()`：
- 优先 localStorage 覆盖 → Tauri 桌面端走新命令 `gateway_info`（返回配置的 scheme+port）→ Web 部署模式用 `location.origin` → 兜底 `http://localhost:10168`
- 改造点：`src/api/client.ts`、`src/api/chat.ts`、`src/composables/useGatewayStatus.ts`、`Guide.vue`、`LiveRouting.vue`、`OnboardingWizard.vue`（展示的接入地址随 scheme 变化）
- **`src-tauri`**：`tauri_cmds` 新增 `gateway_info` 命令注册

### 3. 第三方 Agent 配置生成
`crates/vortex-gateway/src/agent_integrations/` 写入第三方工具的 base_url 按 config 的 TLS 状态生成 `https://` 前缀。

## 验证
1. `cargo check` + `vite build` 通过
2. `VORTEX_TLS=1 ./target/debug/vortex` 启动 → `curl -k https://localhost:10168/api/health` 200，证书 SAN 含 localhost
3. CA 装入钥匙串后 `curl https://localhost:10168/api/health`（无 -k）通过
4. 桌面应用内健康灯变绿（webview 经 https 取 /api/health）
5. 关闭 TLS（默认）行为与现状完全一致
